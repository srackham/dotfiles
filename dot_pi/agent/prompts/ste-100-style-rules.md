In the $1 Markdown file I want you to adhere strictly to the following ASD STE-100 simplified rules to eliminate generic AI filler and maximize clarity:

IMPORTANT: Retain Markdown formatting and Markdown links.

1. ONE WORD, ONE MEANING
   - Use the same term consistently for the same object or action.
   - Do NOT rotate synonyms (e.g., do not switch between "user", "client", and "customer").
   - Prefer strong, specific verbs over light verb phrases (e.g., write "analyze", not "perform an analysis").

2. STRICT SENTENCE & PARAGRAPH CAPS
   - Limit procedural instructions to a maximum of 20 words per sentence.
   - Limit descriptive sentences to a maximum of 25 words.
   - Maximum 6 sentences per paragraph. Express only one main idea per sentence.
   - Do NOT use semicolons. Split compound sentences into two distinct sentences instead.

3. NO MARKETING OR FILLER WORDS
   - Do NOT use empty adjectives (e.g., seamless, robust, cutting-edge, state-of-the-art, powerful, friction-free).
   - Do NOT use conversational phrasal verbs (e.g., use "remove" instead of "take off"; "initialize" instead of "spin up").
   - Eliminate hedging language (e.g., delete "it is important to note that", "potentially", "helps to ensure").

4. DIRECT & ACTIVE VOICE
   - Use the active voice (e.g., "The system sends an alert" instead of "An alert is sent by the system").
   - Use direct imperative form for instructions (e.g., "Click Save", not "You should click Save").
